# Peopoll Build Plan

1. Initialize the Expo app and verify web/mobile startup.
2. Connect Firebase Auth and Firestore for user accounts.
3. Model polls, votes, comments, and trend snapshots in Firestore.
4. Build the poll discovery feed and category browsing.
5. Add single/multi-select voting with one vote per user.
6. Implement threaded comments and moderation controls.
7. Create historic trend charts for poll vote history.
8. Wire up web hosting + mobile build/publish workflows.
9. Add ad, subscription, and promoted poll monetization flows.
